# Learning with Dina

A Spanish-learning app and teaching platform. React, TypeScript, Vite and Tailwind on GitHub Pages, with a Supabase Edge Function behind it.

The work is split into workstreams in [docs/workstreams/](docs/workstreams/README.md). Read the file for the workstream you are working on before you start.

## Standing rules
- This repository is public. Keep financial workbooks, prospect lists and the owner's own lesson-plan files out of it.
- Never paste or commit access tokens.
- Deploy the backend only when the owner asks for it in that message.
- No paid services without approval.
- Spanish written for learners needs the teacher's proofread; say so when you add any.
- Run `npx vitest run` and the browser script for the area you changed before pushing.
- Write to the owner in plain, short language, leading with the outcome.
